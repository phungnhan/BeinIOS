⚙️ Cài đặt Cloudflare Proxy & Token

Do chạy dưới dạng Web/PWA, ứng dụng sử dụng Cloudflare Worker Proxy để chuyển tiếp request mà không bị trình duyệt chặn CORS.

Xem hướng dẫn dựng worker miễn phí trong thư mục cloudflare-proxy/.
Lấy từ Developer Tools (F12) trên trình duyệt máy tính sau khi đăng nhập Beincom.
Trạng thái: Chưa kiểm tra kết nối.
